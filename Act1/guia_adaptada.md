# Adaptación de la consigna

El repositorio remoto estaba vacío al iniciar la actividad y no incluía una guía de código para modificar. Por ello, esta es la adaptación documentada de la consigna suministrada.

| Requisito | Aporte realizado |
| --- | --- |
| Yahtzee clásico con 2 jugadores | Motor de 13 turnos por jugador, cinco dados y hasta tres lanzamientos. |
| Distribución uniforme | Cada dado se obtiene con `randint(1, 6)`. |
| Método de Montecarlo | La estrategia `mc` estima por muestreo la utilidad de conservar dados para una categoría. |
| Explotación de resultados | Modo `simulate`, promedios, mínimos, máximos, victorias y archivo JSON reproducible. |
| Diseño y metodología | Secciones de metodología y diseño en `informe_tecnico.html`. |
| Resultados y conclusiones | Experimento con 100 partidas documentado en el informe. |
| Entrega en GitHub | Código y documentación dentro de `Act1`. |

El juego se basa en el [reglamento oficial de Hasbro](https://www.hasbro.com/common/instruct/yahtzee.pdf), que se cita en el informe.
